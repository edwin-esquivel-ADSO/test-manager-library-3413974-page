Manager Library

Sistema integral de gestión de préstamos y catálogo bibliotecario desarrollado mediante Spec-Driven Development (SDD) en React y PHP (Laravel).

Arquitectura y ADRs Características Repositorios

Decisiones de Arquitectura (ADR)

🏛️

ADR-001 · Propiedad del Esquema

El contenedor de infraestructura arranca con una base de datos vacía. El 100% del DDL (tablas, restricciones y semilla inicial) reside en las migraciones de Laravel.

⚡

ADR-002 · Concurrencia y Restricciones

Garantía estricta de stock disponible mediante restricción CHECK en el motor (0 <= available_copies <= total_copies). Si dos bibliotecarios solicitan el último ejemplar, el sistema responde con 409 BOOK_NOT_AVAILABLE.

🛡️

ADR-003 · Baja Lógica

Los libros no sufren borrado físico. Se utiliza deleted_at para preservar la integridad histórica de préstamos pasados. Un libro con préstamos abiertos no puede ser dado de baja.

❄️

ADR-004 · Valores Congelados

Las líneas de préstamo congelan el título, ISBN y categoría del momento del préstamo. Los reportes estadísticos permanecen inmutables aunque el catálogo sufra renombrados posteriores.

Invariantes de Dominio Implementadas

📋 Registro Transaccional

Préstamos de 1 a 3 libros por operación con vigencia automática de 14 días (UTC).

🚫 Límite por Socio

Máximo 3 libros activos por socio. Si intenta solicitar más, la API responde 422 MEMBER_LIMIT_EXCEEDED.

⏳ Bloqueo por Vencimiento

Cualquier socio con préstamos vencidos no puede adquirir nuevos préstamos (409 MEMBER_HAS_OVERDUE).

🔄 Estado Calculado Dinámicamente

Los estados open, overdue y closed se calculan en tiempo de ejecución. Cero redundancia en base de datos.
